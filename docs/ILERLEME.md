# Halisland: İlerleme Notları

Bu dosya geliştirmenin nerede kaldığını tutar. Her oturum işe buradan başlar, iş bitince burayı günceller.

## Çalışma kuralları

- Her faz ayrı bir branch (`faz-N-...`) ve ayrı bir PR olur. PR'lar squash ile merge edilir ve branch silinir.
- Commit'ler yalnızca Halil adına atılır (`Halil İlgez <65055768+halililgez@users.noreply.github.com>`). Co-author satırı eklenmez.
- Merge'den önce `npm run build` (tip kontrolü) ve `cargo build` (src-tauri) hatasız geçmelidir.
- Masaüstü: `npm run tauri dev`. Ada, adanın boyutundaki şeffaf bir penceredir. Açılırken önce pencere büyür, kapanırken ada küçüldükten sonra pencere küçülür (`src/composables/useIsland.ts`). Boyutlar `COMPACT` / `EXPANDED` sabitlerinde tutulur.
- CI (`.github/workflows/ci.yml`): her PR'da Windows ve macOS üzerinde `npm run build` + `cargo clippy -D warnings`. Windows'a özgü kod (SMTC) bu oturumun Linux ortamında derlenemiyor; doğrulaması CI'dadır, PR yeşil olmadan merge edilmez.
- Müzik `src-tauri/src/media.rs` (Windows: `windows` crate 0.62, async çağrılar `.join()` ile beklenir). Olaylar: `media-update` (saniyede bir), `media-artwork` (şarkı değişince, data URL). Kapak rengi `src/utils/color.ts`.
- Cam efekti `src-tauri/src/glass.rs` + `src/composables/useGlass.ts`. Windows'ta `SetWindowCompositionAttribute` (acrylic/blur) kullanılır; Windows 11'in Mica/Acrylic backdrop API'si pencere odakta değilken düz renge döndüğü için uygun değil. Pencere, frontend'in her karede bildirdiği ada şekline `SetWindowRgn` ile kırpılır. Bölge verilen pencerede Windows eski başlık çubuğunu çizdiği için çerçeve stilleri (WS_CAPTION vb.) kaldırılır. tao bu stilleri bazı durumlarda (açılış, kilit ekranından dönüş) geri koyuyor; `start_frame_guard` saniyede bir bakıp yeniden temizler. Cam açıkken `<html>` `glass` sınıfını alır, ada arka planı daha saydam olur.
- Claude Code: hook'lar JSON'u `POST /claude/hook`'a gönderir (`claude.rs`); durum `hook_event_name`'den çıkar, oturumlar `session_id` ile ayrı tutulur, ada en son hareket eden oturumu gösterir. Pencere bulma (`terminal.rs`, Windows): istemci portu → curl PID'i (`GetExtendedTcpTable`) → süreç ağacında yukarı → görünür ana penceresi olan ilk süreç. Klasik konsolda pencere `conhost.exe`'dedir. Rust testleri: `cd src-tauri && cargo test`.
- Ayarlar `src-tauri/src/settings.rs` (`%APPDATA%\com.halil.halisland\settings.json`), değiştirme yeri tepsi menüsü (`tray.rs`). Aynı menü adaya sağ tıklayınca ve açık adadaki dişliyle de açılır (`open_menu` → `popup_menu`; öncesinde `set_focus` çağırma, menü kapanınca masaüstü yeniden çizilmeyip koyu iz kalıyor). "Claude Code'u bağla" `hooks.rs` ile `~/.claude/settings.json`'a hook ekler/kaldırır (yedek: `settings.json.halisland.bak`). Frontend yalnızca okur (`useSettings`, `settings-changed` olayı). Konum: pencere taşınınca yatay merkez + üst kenar bellekte güncellenir, 2 saniyede bir diske yazılır; açılışta monitör hâlâ bağlıysa geri yüklenir. Tek kopya: `tauri-plugin-single-instance`. Açılışta başlatma: `tauri-plugin-autostart` (gerçek durum her açılışta işletim sisteminden okunur).
- Ada aç/kapa güvenlik ağı (`useIsland`): WebView odakta olmayan pencerede `:hover` tutmuyor ve bazen sahte `mouseenter` gönderiyor. Ada açıkken 1,5 sn'de bir `cursor_over_island` ile gerçek imleç konumuna bakılır; dışarıdaysa kapanır.
- Elle test: Git Bash'te `echo` `\\` dizisini bozar; JSON'u `printf '%s'` ve düz eğik çizgili yollarla gönder.
- Claude Code durumu `127.0.0.1:47821` üzerinden gelir (`src-tauri/src/claude.rs`). Hook ayarları README'de.
